---
title: Course Authoring Skill
description: Skill that creates, assigns and evaluates companyLEARN courses from documents, companyRAG collections or SharePoint content.
label: Course authoring
---

Use this skill when an agent should create a companyLEARN course from a document, a companyRAG collection or SharePoint content, change a draft, assign a course or evaluate learner progress. The course is always created as a draft and only published after your explicit confirmation.

:::note
The `learn_admin_*` tools of the **Learn** MCP server are only available to companyLEARN admins. Lessons are text (markdown); add images and videos afterwards in the companyLEARN editor.
:::
